## 四个拟议的核心组成部分

| 层次 | 组成部分 | 在拟议框架中的功能 |
|:--|:--|:--|
| 认识论根基 | **信息同构定律** | 研究统计结构在何种条件下承载体制结构的信息。 |
| 本体论 | **因子层级定律** | 区分规则因子与执行因子，并研究两者的交互作用和切换角色。 |
| 认识论标准 | **可检验性原则** | 为多因子系统中的因子重要性主张提出操作性检验要求。 |
| 方法论 | **可检验性规范** | 用六个功能维度组织系统性检验，并将具体实现工具视为可替换的。 |

同一研究计划针对不同目的采用三个名称：自然科学语境中的**因子层级体系**、哲学语境中的**信息同构认识论**，以及方法论/工程语境中的**科学发现操作系统**。这是作者对同一研究计划的概念性表达，不代表机构隶属关系。

## 研究涉及的领域

- **金融与资产定价：** 双锚定价、中美利差体制、国债估值、汇率与资本流动。
- **天文学：** 体制依赖的测量、恒星模型自洽性，以及作者提出的 K/G 过渡区“汤氏断点”（Tang Break）。
- **统计物理：** 对二维、三维 Ising 模型开展结构断点研究。
- **粒子物理：** 基于粒子数据模式进行体制边界分析。
- **化学：** 基于体制的元素周期趋势分析与钙—镧奇异性结果。
- **核物理：** 对核壳结构、幻数和核素图进行体制切换分析。

以上定量结果和理论重新解释均是作者在相应论文与预印本中报告的主张。目前的跨学科记录来自作者自己的研究计划；尚未建立这些领域均已获得独立第三方复现的证据。每篇论文仍应结合其自身假设、方法、证据与限制进行评价。
